# No Meat Naan — Play & Earn v0.3

## Run locally
1. Extract the ZIP and open the `nmn-brand-refresh` folder in VS Code.
2. Run `npm.cmd install`
3. Run `npm.cmd run dev`
4. Open http://localhost:3000

## Changes in v0.3
- Home landing page now has large on-screen action cards for Menu, Games and Rewards; no bottom navigation on the initial page.
- A fixed bottom navigation appears on inner pages for quick movement between Home, Menu, Games, Rewards and Café.
- Games hub shows six planned mini-games. Fruit Slice is playable; five are marked Coming Soon.
- Fruit Slice is a 30-second touch/mouse swipe game with fruit targets and score-based sample rewards.
- Retains the supplied No Meat Naan logo and blue/cream/brown brand direction.

## Demo limitations
Independent concept demo, not an official café service or partnership. Menu items/prices were transcribed from supplied May 2026 menu images and must be verified with the café. Reward tiers are illustrative and require owner approval. Game score, coupon creation, redemption and dashboard figures are client-side demo behaviour, not secure production systems. No real QR analytics, backend, POS, ordering or payment integration.
